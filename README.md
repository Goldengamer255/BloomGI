# BloomGI: Chronic Symptom Analytics Platform

BloomGI is a full-stack web application designed to help individuals managing chronic gastrointestinal conditions track their daily symptoms, map comfort trends, and identify environmental triggers.

## Tech Stack
- **Frontend:** React, Vite, ESLint
- **Backend:** Node.js, Express
- **Database:** MongoDB (Planned)
- **DevOps:** GitHub Actions (CI/CD)

## Local Development Workflow
To run the application locally, start both the frontend development server and backend engine simultaneously:

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm run dev` (Runs on http://localhost:5173/)

### Backend Setup
1. `npm install`
2. `npm start` (Runs on port 5000)
